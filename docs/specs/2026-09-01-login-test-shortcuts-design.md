# 登录页测试账号快捷填充设计

## 目标

在测试阶段降低切换客服与主管演示账号的输入成本，同时不改变现有认证与权限边界。

## 范围

- 在登录表单上方显示“测试账号快捷填充”。
- 使用两个浅色、虚线边框的 Ant Design 按钮：客服账号与主管账号。
- 客服按钮只填入 `cs1` / `secret123`；主管按钮只填入 `sv1` / `secret123`。
- 点击按钮后不提交表单，用户仍需明确点击“登录”。

## 非目标

- 不修改登录接口、JWT、RBAC、默认跳转或后端演示账号初始化。
- 不自动登录，不新增账号、环境变量或配置项。

## 验收与测试

- 前端静态测试验证两个按钮、对应身份值、虚线按钮样式和“非提交”语义。
- 先运行新增测试并确认其因功能缺失失败，再实施最小前端修改。
- 运行前端静态测试、生产构建，并在本地登录页实际点击两个按钮核验字段填充。
