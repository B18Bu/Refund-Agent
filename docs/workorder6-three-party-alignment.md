# 三方对齐与防御决策记录（工单 6）

> AI-A（逻辑分析）/ AI-B（工程实现）/ 人工（执行人）三方对齐记录。

## 1. 关键决策

| 决策点 | 结论 | 理由 |
| --- | --- | --- |
| 检测引擎 | 规则引擎为主 + 可选 LLM 增强 | 规则 5：判断类任务可上模型，但路由/拦截必须确定性可控 |
| 拦截阈值 | 风险分 ≥0.85 | 对齐工单 6 决策阈值；用样本集调优 |
| 拦截语义 | 强制 HUMAN_REVIEW，不设自动放行 | 宁挂勿错退，防止注入劫持退款路径 |
| 节点位置 | OCR 之后（`ocr → critic`） | Critic 需要 OCR 文本检测图片内嵌注入 |
| 脱敏范围 | 手机号/身份证/银行卡/API Key/邮箱 | 对齐工单 6 MVP 的 PII 列表 |
| 掩码文本用途 | LLM 材料 + 日志/轨迹/Telemetry | 原始文本仅存内部库审计 |
| 与沙箱关系 | 独立实施，不依赖沙箱 | 沙箱继续推迟，本方案不受影响 |

## 2. 风险与裁决

- **误报风险**：规则命中正常客诉 → 保留合法样本回归集，阈值可配置，误报率入报告。
- **漏报风险**：未知变体 → 保留规则扩展点（特征库可追加），红蓝对抗持续补充样本。
- **LLM 不可用**：规则引擎独立生效，增强仅告警。
