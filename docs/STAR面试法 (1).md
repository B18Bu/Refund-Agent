## <font style="color:rgb(0, 0, 0);">主要内容</font>
<font style="color:rgb(51, 51, 51);">在招聘面试中，仅仅通过应聘者的简历无法全面了解应聘者的知识、经验、技能的掌握程度及其工作风格、性格特点等方面的情况。而使用STAR技巧则可以对应聘者做出全面而客观的评价。</font>

<font style="color:rgb(51, 51, 51);">首先要了解应聘者</font>[<font style="color:rgb(51, 51, 51);">工作业绩</font>](https://baike.baidu.com/item/%E5%B7%A5%E4%BD%9C%E4%B8%9A%E7%BB%A9/5574692?fromModule=lemma_inlink)<font style="color:rgb(51, 51, 51);">取得的</font>**<font style="color:rgb(51, 51, 51);">背景（SITUATION）</font>**<font style="color:rgb(51, 51, 51);">。通过不断提问与工作业绩有关的背景问题，可以全面了解该应聘者取得优秀业绩的前提，从而获知所取得的业绩有多少是与应聘者个人有关，多少是和市场的状况、行业的特点有关。</font>

<font style="color:rgb(51, 51, 51);">其次，要详细了解应聘者为了完成业务工作，都有哪些</font>[**<font style="color:rgb(51, 51, 51);">工作任务</font>**](https://baike.baidu.com/item/%E5%B7%A5%E4%BD%9C%E4%BB%BB%E5%8A%A1/11020854?fromModule=lemma_inlink)**<font style="color:rgb(51, 51, 51);">（TASK或O:Objective）</font>**<font style="color:rgb(51, 51, 51);">，每项任务的具体内容是什么样的。通过这些可以了解应聘者的</font>[<font style="color:rgb(51, 51, 51);">工作经历</font>](https://baike.baidu.com/item/%E5%B7%A5%E4%BD%9C%E7%BB%8F%E5%8E%86/485164?fromModule=lemma_inlink)<font style="color:rgb(51, 51, 51);">和经验，以确定他所从事的工作与获得的经验是否适合所空缺的职位。</font>

<font style="color:rgb(51, 51, 51);">再次，继续了解该应聘者为了完成这些任务所采取的</font>**<font style="color:rgb(51, 51, 51);">行动（ACTION或KR:Key Result）</font>**<font style="color:rgb(51, 51, 51);">，即了解他是如何完成工作的，都采取了哪些行动，所采取的行动是如何帮助他完成工作的。通过这些，可以进一步了解他的工作方式、</font>[<font style="color:rgb(51, 51, 51);">思维方式</font>](https://baike.baidu.com/item/%E6%80%9D%E7%BB%B4%E6%96%B9%E5%BC%8F/10966257?fromModule=lemma_inlink)<font style="color:rgb(51, 51, 51);">和</font>[<font style="color:rgb(51, 51, 51);">行为方式</font>](https://baike.baidu.com/item/%E8%A1%8C%E4%B8%BA%E6%96%B9%E5%BC%8F/8969999?fromModule=lemma_inlink)<sup><font style="color:rgb(51, 102, 204);"> </font></sup><font style="color:rgb(51, 51, 51);">。</font>

<font style="color:rgb(51, 51, 51);">最后，才来关注</font>**<font style="color:rgb(51, 51, 51);">结果（RESULT）</font>**<font style="color:rgb(51, 51, 51);">，每项任务在采取了行动之后的结果是什么，是好还是不好，好是因为什么，不好又是因为什么。</font>

<font style="color:rgb(51, 51, 51);">这样，通过STAR式发问的四个步骤，一步步将应聘者的陈述引向深入，一步步挖掘出应聘者潜在的信息，为企业更好的决策提供正确和全面的参考，既是对企业负责（招聘到合适的人才），也是对应聘者负责（帮助他尽可能地展现自我，推销自我），获得一个双赢的局面。</font>

# 一、什么是 STAR 面试法
STAR 是目前互联网、AI、大厂、金融科技公司最常用的行为面试方法（Behavioral Interview）。

STAR =

| 缩写 | 英文 | 中文 |
| --- | --- | --- |
| S | Situation | 背景情况 |
| T | Task | 任务目标 |
| A | Action | 采取行动 |
| R | Result | 最终结果 |


其核心思想：

> 不要只说你做过什么，而要证明你是如何做成的。
>

很多候选人的回答：

❌ 我参与了RAG项目  
❌ 我负责知识库建设  
❌ 我做了向量检索

这种回答无法体现价值。

面试官真正想听的是：

+ 项目为什么做？
+ 当时遇到了什么问题？
+ 你负责什么？
+ 你具体怎么解决？
+ 结果如何量化？

这就是 STAR。

---

# 二、STAR 模板
可以套用下面的公式：

```latex
S：
项目背景是什么？

T：
你的目标是什么？

A：
你具体做了什么？
（重点讲技术细节）

R：
最终效果是什么？
（必须量化）
```

# 五、STAR回答（标准版）
## S（Situation）
项目背景

```latex
我们公司有300多名投研分析师。

每天需要阅读大量：

- 上市公司年报
- 券商研报
- 电话会议纪要

平均每个分析师每天阅读时间超过4小时。

信息检索效率较低。

因此公司决定建设金融投研RAG助手，
帮助分析师快速获取投资研究信息。
```

面试官听到这里：

✓ 知道项目价值

---

## T（Task）
你的职责

```latex
我担任AI应用工程师。

负责：

1. RAG整体方案设计
2. 数据处理Pipeline
3. 向量检索优化
4. Prompt工程设计
5. 线上效果评估
```

面试官听到：

✓ 职责清晰

---

## A（Action）
这是重点，占70%。

---

### Action 1
数据治理

最开始数据质量很差：

```latex
PDF
Word
扫描件
网页
Excel
```

问题：

```latex
格式不统一
OCR错误
表格丢失
```

我的方案：

```latex
MinerU
OCR
Layout解析
表格识别
```

构建统一数据清洗流程：

```latex
原始文档
 ↓
OCR
 ↓
版面分析
 ↓
结构化JSON
 ↓
Chunk
 ↓
Embedding
```

---

### Action 2
Chunk优化

最初：

```latex
固定500字符切分
```

效果很差。

例如：

```latex
营业收入
Chunk1

增长原因
Chunk2
```

语义断裂。

改进：

```latex
章节级切分
标题切分
语义切分
```

例如：

```latex
第三章 财务分析

Chunk1:
收入分析

Chunk2:
利润分析
```

召回率明显提升。

---

### Action 3
混合检索

最初：

```latex
Embedding检索
```

问题：

```latex
股票代码
财务指标
专有名词
```

容易漏召回。

例如：

```latex
600519
ROE
PE
PB
```

于是设计：

```latex
BM25
+
Vector Search
+
Rerank
```

架构：

```latex
用户问题
      ↓
 BM25召回
      ↓
 Vector召回
      ↓
 合并去重
      ↓
 Rerank排序
      ↓
 TopK
```

效果提升明显。

---

### Action 4
Rerank优化

引入：

```latex
BGE-Reranker
```

解决：

```latex
召回正确
排序错误
```

的问题。

Top5命中率提升。

---

### Action 5
Prompt优化

设计金融领域Prompt模板：

```latex

资深证券分析师

要求：
必须引用来源
不得编造
优先引用最近报告
```

同时加入：

```latex

Source Trace
```

实现：

```latex
答案
+
出处
+
文档链接
```

增强可信度。

---

### Action 6
评测体系建设

建立测试集：

```latex
1000个投研问题
```

覆盖：

```latex
财务分析
行业分析
宏观分析
公司研究
```

指标：

```latex

MRR
HitRate
Faithfulness
Answer Relevance
```

实现持续优化。

# 七、面试官追问示例
## Q1：RAG最大的难点是什么？
STAR回答：

```latex
S：
金融文档非常长。

T：
提高召回率。

A：
采用章节级Chunk、
Hybrid Search、
Rerank优化。

R：
Recall@10从72%提升到94%。
```

---

## Q2：为什么不用微调？
STAR回答：

```latex
S：
知识更新频繁。

T：
降低维护成本。

A：
采用RAG而非Fine-tuning。

R：
知识更新从周级缩短到分钟级。
```

---

## Q3：你最大的贡献是什么？
STAR回答：

```latex
S：
系统回答经常出现幻觉。

T：
降低幻觉率。

A：
设计引用追踪、
Rerank、
Prompt约束。

R：
Faithfulness从65%提升至92%。
```

# 八、AI面试最强STAR公式
对于 RAG、Agent、AIGC、大模型项目，推荐使用下面的结构：

```latex
S（业务痛点）
↓
T（目标指标）
↓
A1（方案设计）
↓
A2（技术实现）
↓
A3（性能优化）
↓
A4（线上治理）
↓
R（量化结果）
```

套用到金融投研RAG助手：

```latex
业务痛点：
分析师每天阅读4小时研报

目标：
提升检索效率

技术方案：
RAG + Hybrid Search + Rerank

技术实现：
LangChain + Milvus + BGE

性能优化：
Chunk优化 + 缓存 + Prompt

结果：
准确率91%
召回率94%
节省2.5小时/天
```

这样的 STAR 回答不仅说明“做过项目”，还能体现你的**业务理解能力、系统设计能力、RAG优化能力和结果导向思维**，非常适合 AI工程师、算法工程师、AI应用开发工程师、大模型工程师等岗位面试。
