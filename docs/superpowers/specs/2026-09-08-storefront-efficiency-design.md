# 品牌优选商城高效率交易型改版设计

## 目标

将消费者商城首页从多层说明和并列面板，调整为搜索与商品浏览优先的交易界面。保留官方目录、订单、售后和悬浮智能客服能力，但不把客服重新放入导航。

## 设计决策

采用“高效率交易型”方向，使用中性白灰为商品与内容底色，可信蓝作为所有主操作色。橙色只用于“新品”或其他短期提醒标签，不作为大面积背景或主按钮色。

不采用精品陈列型的深色与金色方案，因为商城同时售卖手机、配件和日用品，需要支持高密度、多价格带的目录浏览。也不采用大面积促销红色，避免与退款、错误等风险状态混淆。

## 信息架构

### 顶部导航

保留品牌入口、全局商品搜索、订单入口和购物车。移除重复的工具栏文字及固定客服导航入口。商品分类、手机数码、耳机配件和售后服务保留为一层紧凑主导航。

### 首页首屏

首屏由主会场与快速探索组成：

- 主会场左侧展示单一价值主张、目录来源说明和一个“浏览精选商品”主操作。
- 主会场右侧显示当前目录中可用的真实主推商品图，不使用抽象装饰图。
- 主会场下方以可点击分类标签提供手机、耳机、充电、数据线、其他配件等快速入口。
- 官方来源、规格透明、订单可查与售后承接收束为一条低干扰服务说明带。

左侧分类面板与右侧服务面板不再占据首屏宽度，避免与商品浏览任务竞争。

### 商品发现

筛选区域保持关键词、品牌和价格带三种确定性条件，改为更紧凑的横向工具栏。商品区使用响应式网格：桌面四列、平板三列、手机两列。商品卡展示真实图片、品牌、名称、规格摘要、起售价和详情入口；卡片不承载冗余营销文案。

### 智能客服

智能客服继续以右下角悬浮圆形按钮提供，打开后为可关闭的多轮对话浮窗。它在所有消费者商城页面保持相同位置，默认不遮挡商品筛选与移动端底部操作。

## 视觉系统

- 页面背景：冷调浅灰，区分商品区与纯白内容面。
- 内容面：白色，边框使用低对比蓝灰，不叠加装饰性阴影。
- 主色：可信蓝，用于搜索按钮、主操作、已选筛选项、链接和客服入口。
- 辅色：低饱和青绿仅用于成功或可用状态；橙色仅用于短期商品标签。
- 文本：深墨色标题、深灰正文、蓝灰辅助说明；正文对比度满足 WCAG AA。
- 圆角：工具和浮窗最大 8px；商品卡保持方正、可扫描的目录感。
- 排版：以现有 `Inter` 与 `Microsoft YaHei` 系统字体栈为主，不引入在线字体请求。

## 响应式与可访问性

- 375px 起优先保留搜索、商品分类、筛选与悬浮客服；次级导航可横向滚动或收束。
- 所有图标按钮提供可访问名称与可见焦点状态，触控目标不小于 44px。
- 商品图维持固定宽高比，异步加载不引起布局跳动。
- 筛选、分类与客服可通过键盘操作；客服浮窗支持 Escape 关闭。
- 在 `prefers-reduced-motion` 下禁用商品卡位移动画。

## 范围与非目标

本次只修改消费者商城的壳层、首页、商品网格和相关样式，不变更商品、订单、退款、鉴权、客服 API 或数据库结构。不新增促销、支付、评价、收藏或推荐算法。

## 验收

1. 消费者商城没有固定“智能客服”导航项，右下角悬浮入口仍可打开客服对话。
2. 首页首屏不再并列展示左侧分类栏、中央主会场和右侧服务卡。
3. 搜索、分类、品牌筛选、价格筛选、商品详情、订单、购物车与售后入口保持可用。
4. 桌面、平板和 375px 宽度下，文本、筛选控件、商品卡及悬浮客服不重叠、不溢出。
5. 前端定向测试、生产构建与统一 Docker 容器健康检查通过。
