# 用户个人中心移动优先分段布局设计

## 目标

优化用户个人信息界面，使订单状态、收货地址和系统定义的购物偏好更容易扫描和操作；采用移动优先的分段布局，并在桌面端自适应扩展。

## 布局方案

- 顶部账户概览：保留“我的”标题和简短说明，右侧提供“全部订单”入口。
- 订单与配送：作为首个高频分段，突出最近订单、状态标签、商品摘要和金额；无订单时保留商城入口。
- 收货地址：展示默认地址和地址列表，新增、编辑、设为默认、删除操作保持可见且满足触控尺寸。
- 购物偏好：以标签网格展示系统定义的品类、品牌、尺寸、预算、购买频率和最近购买商品；偏好值仍遵守用户授权状态。

## 响应式行为

- 移动端：分段单列排列，内容宽度使用页面内边距，操作按钮允许换行并保持至少 44px 点击区域。
- 桌面端：订单分段保持主内容宽度，地址和偏好可在同一视觉层级中并列展示；不引入嵌套卡片。
- 长文本、商品摘要和偏好值允许换行，不截断关键状态。

## 交互与可访问性

- 使用现有 Ant Design Button、Tag、Drawer 和 Link，保留键盘焦点样式与语义标题层级。
- 地址编辑继续使用抽屉表单，保存、加载和失败状态沿用现有反馈。
- 不以颜色单独表达订单状态；状态标签同时提供文字。
- 不改变后端接口、权限校验或个人偏好隐私规则。

## 验收标准

- 移动端 320px 至 640px 宽度下无横向滚动，订单、地址、偏好三个分段均可访问。
- 桌面端页面内容保持可读宽度，分段间距和标题层级清晰。
- 地址新增、编辑、删除、设为默认行为保持现有测试通过。
- 购物偏好标签始终可见，未授权时显示授权状态而不是隐藏标签。
- 前端组件测试与生产构建通过。
