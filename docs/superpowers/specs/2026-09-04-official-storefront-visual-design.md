# 官方商城前端视觉重设计

## 目标

将消费者商城从业务系统式商品列表调整为正式的综合电商门户体验。视觉参考用户提供的三栏商城首页：多层导航、搜索与交易入口、分类菜单、主会场和用户服务面板；不复制参考站点的标识、文案或活动内容。

## 范围与约束

- 仅调整消费者端 `/shop`、商品详情、购物车、结算与订单页面的布局和样式；客服、主管后台不改动。
- 保留现有 FastAPI 接口、JWT/RBAC、目录就绪门禁、购物车、模拟支付、订单和退单逻辑。
- 商品、价格、可售状态、图片和来源仍完全来自已发布的 vivo/小米官方目录；不得添加静态演示商品、伪造促销价或库存。
- 保持键盘可用性、可见焦点、图片替代文本、加载/失败/空状态，以及桌面与移动端响应式布局。

## 信息架构

1. 工具栏：登录状态、订单、售后与客服入口；仅显示当前系统具备的真实路由，不伪造会员、优惠券或运营功能。
2. 搜索栏：品牌标识、宽搜索框、热门关键词、购物车和订单入口。搜索继续调用商品列表已有的关键词参数。
3. 主导航：左侧“全部商品分类”，右侧商城首页与实际分类频道。分类从 vivo/小米已发布商品中推导，不显示无商品类目。
4. 三栏首屏：左侧分类菜单，中间主会场（使用已抓取商品图或中性渐变，不伪造促销），右侧用户欢迎、订单/售后/客服快捷入口和系统公告。
5. 服务保障与商品区：展示“真实目录、服务端价格、模拟支付、可追溯售后”等事实性能力说明；下方继续使用四列、三列、两列响应式商品网格。

## 视觉语言

- 使用白色内容面、浅灰页面背景、深色文字与红色主操作，形成正式综合商城的信息密度。
- 首屏采用左中右栅格：分类菜单、主会场、服务面板；商品图维持固定比例，避免卡片跳动。
- 使用 8px 间距体系；价格使用高对比红色，但不使用促销、原价、折扣、优惠券或虚构销量标签。
- 动效仅限悬停、焦点与加载反馈；尊重 `prefers-reduced-motion`。

## 页面要求

- 商品详情：大图与关键信息左右布局，规格选择、数量和加入购物车操作在价格附近；移动端顺序降级为图片、信息、操作。
- 购物车与结算：使用订单摘要侧栏（移动端转为页面底部），明确总价、地址和模拟支付说明。
- 订单与退单：延续统一的卡片、时间和状态层级，不泄露后台 OCR、风控、审批锁或内部处理信息。

## 验收

- 页面不再出现过期的“VIVO · OPPO”文案，目录来源统一为 vivo 与小米。
- 1440px 首页呈现工具栏、搜索栏、主导航、三栏首屏、服务保障和商品区；窄屏将分类与服务面板收纳为纵向内容，无横向溢出。
- 在真实目录 READY 时可浏览、搜索、筛选、查看详情、加购和下单；目录未就绪时保留既有拒绝和提示行为。
- 以 320px、768px、1440px 宽度验证无横向溢出，核心操作可键盘访问。
- 前端构建与现有商城相关测试通过。
