# 主管政策依据 RAG 设计

## 1. 目标与范围

为主管提供基于项目现有文档和规则的政策依据检索能力，用于工单审批、评测解释和决策复核。首期仅返回带来源的原文片段，不生成新的政策结论，不改变现有退赔决策结果。

首期明确不包含：历史工单相似案例、客服侧入口、自动决策 Agent 调用、外部知识源、LLM 总结回答。

## 2. 现有边界

现有链路为 `OCR → 安全网关 → 意图识别 → 风控/舆情 → decision_rules.decide → 人工审批`。`decision_rules.decide` 是退赔结果的唯一确定性来源，RAG 不得写入或覆盖 `decision`、`final_decision`、金额、欺诈分数、舆情等级和审批状态。

RAG 查询只读取脱敏后的工单摘要、金额、意图标签、风险标签和命中原因。原始 OCR、图片、Token、密码和认证材料不得写入向量库或查询日志。

## 3. 架构

新增 `backend/app/rag/` 模块：

- `documents.py`：扫描白名单目录、解析 Markdown/JSONL、切分 Chunk、计算内容哈希。
- `embeddings.py`：调用本地 embedding 服务；模型通过配置指定，禁止隐式下载。
- `retriever.py`：执行 pgvector 相似度检索、文档版本和访问范围过滤。
- `service.py`：组装主管查询、超时和空结果降级。
- `schemas.py`：定义文档、片段、查询结果响应。

PostgreSQL 新增 `rag_documents`、`rag_chunks`、`rag_query_logs` 表；向量字段使用 512 维 pgvector。文档和 Chunk 保存来源路径、标题、文档类型、版本、哈希、生效时间和访问范围。原始文档仍以仓库文件为准，数据库只保存索引和审计元数据。

本地 embedding 模型作为独立服务运行，FastAPI 通过固定内部地址调用。模型固定为 `D:\\作业\\model\\bge-small-zh-v1.5`，输出 512 维向量；模型不可用时，RAG 接口返回明确的不可用状态，审批和评测主流程继续运行。

## 4. 知识源

首期只索引以下白名单：

- `backend/app/agents/decision_rules.py`
- `backend/app/security/`
- `docs/specs/`
- `docs/guides/`
- `docs/evidence/`
- `specs/001-refund-decision-mvp/`
- `evals/golden/refund_cases.jsonl`

每个片段必须保留相对路径、章节/行号范围、内容哈希和版本信息。归档材料默认不作为正式政策，除非显式标记为可检索来源。

## 5. 查询与接口

新增主管专用接口：

```text
GET /api/tickets/{ticket_id}/knowledge
GET /api/evaluations/knowledge
```

接口必须经过 `require_role(Role.SV)`。工单查询先验证主管可见范围，再构造脱敏查询文本；统一返回：

- `available`：知识检索是否可用
- `query_id`：审计查询标识
- `results[]`：片段文本、来源路径、章节、版本、相似度、文档类型
- `status`：`ok`、`empty` 或 `unavailable`

默认返回最多 5 个片段，并设置最低相似度阈值；低于阈值不返回“可能相关”的内容。

## 6. 前端体验

在主管工单详情和评测中心增加“政策依据”区域：

- 展示加载中、无结果、服务不可用和正常结果四种状态。
- 每条结果展示原文片段、来源文件、章节/行号、版本和相似度。
- 来源路径可展开查看，不把 RAG 结果伪装成系统决策理由。
- RAG 加载失败时，审批按钮和现有评测内容保持可用。

## 7. 安全与可靠性

- 只允许代码配置的知识源路径，禁止用户通过请求参数指定任意文件。
- 文档内容视为不可信材料，不能覆盖系统规则或生成工具权限。
- 文档入库前执行 DLP 脱敏；查询日志只保存脱敏摘要和命中文档 ID。
- PostgreSQL 查询使用参数绑定；向量服务使用固定 URL 和超时。
- embedding 服务、pgvector 或索引不可用时，不阻塞 FastAPI 主事件循环，不影响退赔和审批结果。
- 文档更新通过显式索引命令执行，记录批次、模型版本和失败文件；不在 API 启动时隐式扫描或改表。

## 8. 验收与测试

后端：

- 主管可查询，客服/客户返回 403。
- 工单越权查询返回 404 或统一无权限响应。
- 文档版本和访问范围过滤生效。
- 命中结果包含来源、章节和版本；低相似度返回 `empty`。
- embedding 服务失败、数据库失败和超时均返回 `unavailable`，且审批结果不变。
- 原始 OCR、图片和认证字段不会进入向量库或查询日志。
- 索引命令重复执行保持幂等，文档内容未变化时不重复写入。

前端：

- 正常、空结果、错误和加载状态均可见。
- RAG 失败不隐藏审批操作。
- 主管路由和现有角色隔离回归通过。

部署：

- PostgreSQL 镜像支持 pgvector，迁移由独立一次性服务执行。
- embedding 服务健康检查失败时不会被误认为 RAG 可用。
- 知识索引命令在部署后显式运行并产出可审计日志。

## 9. 分阶段交付

1. 数据库扩展、文档索引命令和本地 embedding 服务健康检查。
2. 主管知识检索 API、权限过滤、脱敏和审计日志。
3. 工单详情与评测中心前端展示。
4. Golden 文档检索评测、失败降级和 Compose 部署验收。
