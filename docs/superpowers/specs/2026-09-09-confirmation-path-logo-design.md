# 「确认路径」Logo 设计规格

## 目标与范围

为项目的电商服务与智能决策场景提供统一、可缩放的 Logo 资产。该标识用于商城、主管后台、浏览器图标和订单已确认等可信状态表达。

本规格只定义品牌资产与使用规则，不修改页面、路由、认证或业务流程。

## 选定方向

采用 A2「确认路径」方向：

- 蓝色圆角方形承载稳定、可信的产品底座；
- 白色折线路径表达从交易到服务处理的清晰流转；
- 橙色确认点及白色勾选表达已确认、可追溯的决策结果；
- 中文字标使用现有产品名称「品牌优选」，英文辅助字标仅用于较宽的横向场景。

标识使用扁平几何图形，不使用渐变、阴影或细节化插画，保证在 32 px 图标尺寸下仍可识别。

## 资产清单

所有图标使用 `viewBox="0 0 90 90"`，通过 SVG 输出，不依赖外部字体或位图资源。

| 文件 | 用途 | 颜色 |
| --- | --- | --- |
| `brand-mark.svg` | 默认应用图标、浅色页面 | 蓝色底、白色路径、橙色确认点 |
| `brand-mark-reverse.svg` | 深色背景页面 | 浅青底、深蓝路径、橙色确认点 |
| `brand-mark-monochrome.svg` | 单色打印、受限媒介 | 单一深蓝色 |
| `brand-logo-horizontal.svg` | 48 px 及以上的页头和文档 | 默认图标加中英文字标 |
| `brand-guidelines.md` | 交付说明与使用规则 | 文档 |

## 使用规范

- 图标最小显示尺寸为 24 px；小于 24 px 时使用单色版，且不附加文字。
- 图标四周的最小留白等于图标宽度的 20%。
- 横向字标最小高度为 32 px；小于该尺寸只使用图标。
- 浅色背景使用默认彩色版，深色背景使用反白版，打印或只有一个可用颜色时使用单色版。
- 禁止改变路径比例、替换确认点颜色、添加阴影/渐变，或将文字标识拆开单独作为品牌 Logo。

## 实现与验证

1. 在 `frontend/src/assets/brand/` 创建上述 SVG 与规范文件。
2. 校验 SVG 均不含外部链接、脚本、位图或个人信息。
3. 以 24、32、48、70 px 渲染检查轮廓与勾选的可辨识度。
4. 不将资产接入现有页面；页面接入必须在后续获得明确需求后单独实施和验证。

## 非目标

- 不进行前端页面改版或导航变更。
- 不替换现有接口、认证、权限或物流/订单逻辑。
- 不生成或保存包含个人信息、本机路径或凭据的资源。
